# Homebrew Tap

Homebrew formulae maintained by Solomon Wakhungu.

## Gronify

Install [Gronify](https://github.com/1solomonwakhungu/gronify):

```bash
brew install 1solomonwakhungu/tap/gronify
```

The formula installs the `gronify` executable and its Node.js and `fastgron` dependencies.

## OpenRig

Install [OpenRig](https://github.com/1solomonwakhungu/openrig), Solomon's fork with native
runtime adapters for OpenCode, Kilo, GitHub Copilot CLI, Cursor CLI, Gemini CLI, Qwen Code,
Cline, Aider, Grok Build, and Antigravity CLI:

```bash
brew install 1solomonwakhungu/tap/openrig
```

The formula installs the `rig` and `openrig-tui` executables, pinned to Homebrew's `node@22`,
and depends on `tmux`. Sign in to the agent CLIs you plan to run before starting a rig.

## discord-cli

Install [discord-cli](https://github.com/1solomonwakhungu/discord-cli):

```bash
brew install 1solomonwakhungu/tap/discordcli-agents
```

The formula is named after the `discordcli-agents` PyPI distribution and installs
the `discord-cli` executable.
